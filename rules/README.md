# Rules: what each sport game must enforce (owner, 2026-10-16)

The owner wants **proper rules** in every sport, the way a real broadcast game plays. Each sheet lists:
- **Must enforce**: the rules the game itself checks, with the whistle, the call on screen and the restart.
- **Game flow**: periods, clock and restarts.
- **Broadcast look**: score bug, replays and cameras.
- **Robot checks**: these become fix tests.

Shorter or kid-friendly modes are fine (shorter periods, assist), but the **rules stay the same**. A rule may be
switched off only in a clearly labelled mode ("Arcade: no offside").

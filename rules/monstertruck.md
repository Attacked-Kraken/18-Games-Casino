# Rules: monster truck (apexmonstertruck.html)

## Must enforce
- **Racing:** 2 trucks side by side on mirror-image lanes, first to the finish wins, knockout rounds to a final.
  Hitting the barrier or missing a jump costs time.
- **Freestyle:** a **90-second** run. Judges score it **0–10** for big air, wheelies, donuts, crushes, saves (almost
  rolling over, but landing it) and tricks (backflip, nose wheelie). The run ends early on a roll-over or a broken
  truck.
- **Skills challenge:** the best single trick (wheelie or donut), scored 0–10.
- **Damage:** hard landings break parts (a wheel comes off), which ends the run.
- **Safety:** the "kill switch". The truck stops instantly when the run ends.

## Game flow
- Event night: racing bracket → skills → freestyle → the champion is crowned (points over all 3).
- Career: unlock trucks and paint jobs (our own designs), and upgrade the engine, suspension and tyres (earned in the
  game, never with real money).

## Broadcast look
- Big-screen replays of the best moments. Judges' scores appear one by one. Pyro fires on the winner.

## Robot checks
- Freestyle run timer of 90 s; the judges' score is between 0 and 10; a roll-over ends the run

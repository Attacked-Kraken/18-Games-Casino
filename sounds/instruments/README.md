# Real instruments (CC0) for Beat Machine

Recorded orchestra samples from VSCO 2 Community Edition (Versilian Studios, CC0 1.0 - see ASSETS.md).
`instruments.json` lists each instrument's sample notes (MIDI numbers); `<instrument>/<midi>.mp3` is one recorded note.
Beat Machine plays the nearest sample, pitched to the note. Pick them under Synth -> "Real instruments".

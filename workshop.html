🏭 The whole game-making system

Everything you can do yourself, fastest first. Nothing here needs Claude or code knowledge.

1. Make a brand-new game - 10 minutes

  1. 🛣️ Track: tap the points, close the loop, split off a branch if you want, name it, Send.
  2. 🧱 Build: scenery (trees, stands, arches, rocks, lights, models), name it, Send.
  3. 🎮 New game: name, your track + pieces, car, colours, laps, rivals - Make it - Send.
  4. Controller: Check, Send. A Muse makes the file, the robot checks, the merge robot merges. It shows on the Game Development page by itself ("New games").

2. Tune any game - seconds, live

Open the game with 🎛️ Studio on (Game Development page → Studio on, or add ?studio=1). The 🎛️ button at the top opens: Tune (speed, grip, steering, rivals, camera distance/height/zoom, engine pitch/loudness/brightness, colours), Place (map from above - tap to drop trees, rocks, cones, tyres, lights, buildings, road pieces, fences, people; drag to move around; erase), Cameras (add your own views: behind / height / side / ahead / zoom - the game's camera button steps through them), Save (only you see it at once; Publish sends it to every player through the controller). F1 and every new starter game have Studio now; the other games get it next.

3. Change the real code - minutes

💻 Code: pick the game, Open, Find the part (the controller's 📘 Manual lists every part of every game and what it does), change it, ▶ Run my version plays your version here. Send works out exactly what you changed by itself.

4. Not sure how to change it? - minutes

Controller → 🔧 Fix it: say it in your words ("colours don't change the car", "add a horn button"). The Mac mini finds the code and writes one message for free ChatGPT; paste its answer back; Check; Send.

5. Big work - hours, by the factory

Muse windows: one job, one part, one pull request. Testers find problems, auditors check them. Give a Muse a job from the controller, or let it build on top of your starter game ("make my Desert Rally cars jump on the ramps").

How everything connects

Workshop / Studio / Code / Fix it  →  a FIX PACK
      → your controller (Mac mini): Check = it matches the real file on GitHub, no keys, no never-words
      → Send = a Muse window types it into a pull request
      → the robot checks it (paperwork) → the merge robot merges it (minutes)
      → the game on the Game Development page has it (refresh)
Undo: Studio "Undo ALL my changes" · Code "Undo all" · Mac mini's own files: Paste a fix → Undo · a game: send the old version back the same way.

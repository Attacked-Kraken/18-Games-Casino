# 18 Games Casino

A small stand-alone web page with two games: Velvet 21 (blackjack with fun chips only, 18+) and Steelfront (3D shooter, 13+).
The casino floor also links 27Hoops (3D 5-on-5 basketball, 13+): tap the round Hoops button at the bottom right of the floor, or find it in the games list. Its players are real 3D bodies from characters/base-human-v2 in photo-style kits.
Separate project with no connection to any other site. Plain static files: open index.html. Saves stay on the player's device.

HOW TO PLAY

Striding: tap STRIDE LEFT / RIGHT alternately (or ArrowLeft / ArrowRight, A / D). Alternating builds speed fast; same-side taps are weak. Speed fades — keep striding.
Starts: wait for the pistol on "SET". Moving early = false start. Two false starts = disqualified.
Distance: watch STAMINA. Sprinting all-out early will empty the tank — save something for the final kick.
Hurdles: tap ACTION (or Space) to jump each hurdle. Clip one and you lose speed.
Relay: in the 20m exchange zone tap ACTION to pass the baton. Clean timing = flying start for the next leg.
Jumps: stride the run-up, tap ACTION on the board (over it = foul), then tap ACTION to set the takeoff angle. Triple jump: two more timed taps for hop and step.
High jump / Pole vault: stride in, tap ACTION in the takeoff zone, then tap ACTION when the marker is inside the green window to clear the bar.
Throws: tap ACTION to lock the power meter, then tap ACTION to release at the right angle. Discus / hammer: tap in rhythm with the 3 spin pulses first. Javelin: stride the run-up for extra speed.

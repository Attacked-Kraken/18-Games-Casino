The loop - how a fix travels

Your words → a PR → the robot → live

What: Every change to a game, by you, a Muse or a Claude, goes the same road: a branch + a pull request (PR) → the robot's paperwork checks (file guard, part guard, look guard) → green = the merge robot merges it into main → the live site updates in a minute or two. Red = the exact red lines go back to the window that made it.

How you use it: you never run commands. You tap Send on a tool (Studio, Workshop, Fix it, Paste a fix, Versions) or message a window; the system does the rest and the PR page shows where it is.

Game Development page (sports.html)

Game cards · Play

What: the live lineup - every game, newest build, one tap to play. NEW GAMES shows any game page that landed in the repo (a Muse's, or one from Workshop) by itself.

How: tap a game tab at the top to jump to its card; Play opens it. Refresh loads the newest builds.

✏️ Pencil · 🎥 Record · 📸 Snap · 📤 Send

What: while a game runs here you can circle a problem, record the screen with your drawing, snap a picture and send it all to your controller, which turns it into a note for the crews.

How: the small bar at the top of a running game. The 📤 opens your controller through its away link, so it works from anywhere.

☰ Tools menu

What: one button at the top of the page with every tool as a tab: Workshop, Studio on/off, Pull requests, Glossary, How it all works, Fix it, Paste a fix, Manual, Versions, Code, My settings, System map, Master list.

How: tap ☰, tap a tab, "‹ Back" closes it. Nothing else sits piled on top of the page.

🎛️ Studio ON / OFF

What: the switch that puts the in-game editor (Studio) into every game you play from this page.

How: in the ☰ menu. ON = a small Studio button appears in the game; OFF = the plain game. The switch is remembered on this phone.

Studio - the editor inside every game

Scene tab

What: tap anything in the live game → its name, where it sits, its numbers. Tools: Pick, Move, Lift, Turn, Size by dragging; colour, Hide, Delete, Put it back, Swap for a model, Freeze camera; a list of everything in the scene; "the code that made this".

How: tap the Studio button in the game, tap a thing, drag or use the sliders. Changes are saved on this phone first; Save → Publish sends them as a fix.

🛣️ Track tab (F1, Racer)

What: the circuit as a map: points, the FINISH line (first point), pit in/out, DRS, you. Drag points, move the finish line, add/remove points, heights, road width.

How: edit → "✍️ Put it in the code" → ▶ Run drives your version → Send. "Save as a NEW circuit" adds a whole new track to F1 (Owner circuits).

💡 Lights tab

What: every light in the scene: on/off, brightness, colour, place, reach, shadows; add point, spot, sun or sky lights.

How: slide, look, Save. Reset puts the game's own lights back.

🎨 Look · 🎥 Record

What: Look = saturation, contrast, brightness, hue, warmth over the whole picture. Record = 10 or 30 seconds of the game as a video (share sheet on the phone).

🛡️ Rules tab = the check builder

What: tap a thing + pick a rule (stays, above ground, size ±%, within N m of another thing, colour, on screen, count). The rule is measured live; it must PASS today before it is added. Send turns it into a robot test the game must keep passing forever.

How: this is how a complaint becomes a permanent check without code.

⚡ Blocks tab (games on the Apex Engine)

What: behaviour with no code: WHEN something happens (a lap, the finish, off the road, the race start, every N seconds) → THEN do things (big words on screen, a sound, slow motion, camera shake, points, end the game, say it out loud). Words in {curly} fill from the event: LAP {lap}!

How: pick WHEN, an optional IF (lap ≥ 2), THEN + its words or numbers → Add. ▶ Test fires it now. Save → Publish puts the blocks in the game for everyone; the robot replays them exactly.

⚙️ Physics · Tune · Place · Cameras

What: Physics/Tune = the game's declared sliders (speed, grip, engine sound, fov…). Place = drop trees, stands, poles, rocks on a map from above. Cameras = your own camera views (back/up/side/ahead/fov); the game's camera button steps through them.

💻 Code · 🐞 Log · 👁️ Watch

What: Code = read and edit this game's code, ▶ Run my version, link to the exact line on GitHub and GitHub's editor. Log = the game's errors and console lines with file:line (the phone has no developer console - this is it; the Studio button shows 🐞N while errors sit). Watch = pin any live number or switch of the running game on screen and change it live.

Save · Publish

What: Save keeps your Studio changes on this phone. Publish sends them through the controller's Paste-a-fix as mods/<game>.json, so the game loads them for everyone.

Controller (home Wi-Fi or the AWAY icon)

🧪 Phase 2 button

🆘 Help desk · 🔒 Public repo · 🛡️ Safety · ✋ Learned

📋 Master list (live)

🧰 My tools

What: Pull requests, Workshop + games, Fix it, Paste a fix, Manual, My settings, Code, Versions, System map, Glossary - everything that works without Claude.

🔀 Pull requests /prs

What: every open PR in plain words: 🟢 green (the merge robot merges it; .github ones never), 🔴 red with the robot's exact Reason lines, 🟠 conflict, ⏳ checking, 📝 draft, ⏩ behind; its window, age, ▶ Play it, 🔗 GitHub.

How: buttons = Merge it · Send back the red lines · Fix the conflict · Update from main · Close it (two taps) · Tell its window (your words). Each tap is ONE order typed to that window; a red PR is refused before anything is typed.

🕘 Versions /versions

What: every merge of a game (date, title, PR, who, 📍 LIVE NOW). ▶ Play that version. ↩️ Put this version back (two taps) = a roll-back order to the game's auditor window, followed to its PR and merge.

🔧 Fix it /fixit

What: 5 steps: pick the game → Broken or Add new → your words → the system finds the code that matches your words → one ChatGPT message is made for you (problem, why first, the FIX PACK format, the code, an index of the file) → paste the answer → Check → Send.

🩹 Paste a fix /fix

What: you paste a FIX PACK (GAME / FILE / WHY / TEST / OLD: / NEW: / END). Check reads the real file on GitHub and every OLD block must be found exactly once. Send types it to the game's builder window as an exact order; the window makes a normal PR the robot must pass. 🧭 My fixes shows where each one is. "Copy the ChatGPT prompt" gives ChatGPT the format.

📘 Manual /manual

What: how to fix anything / add a feature, the worked colours example, and a live index of each game file (parts, lists, ids, test links) - tap a name, you land on that line in the Code page.

📖 Code /code

What: search and read the approver script, the pages and the 6 game files; "Make a ChatGPT prompt" copies the section + your words + the FIX PACK format; Edit on GitHub opens the exact line.

⚙️ My settings /settings

What: the numbers you may change yourself: hands-off seconds, pick-one time, card-sit, frozen, mouse speed and click rest, card scan speed, courier routes (GPT on/off, who gets what), Claude wake cap. "normal" resets one. Safety locks are not settings on purpose.

🗺️ System map /map

What: every part of the system on one page: how a game gets fixed without Claude, where to change what, the words to search for, what stays locked, what to do if something goes wrong.

💬 Message a Muse · Message all · ⏸ Pause

What: type to one window or all 12; your messages are never held by the automatic switches. Pause stops the Mac's hands for 5 / 15 / 60 min or until Resume.

🎚️ Automation level · Cards only · All automatic messages off

What: per window 0-5 (0 = cards only … 5 = everything). The two master switches are ON (Oct 30): the Mac presses approval cards and types nothing by itself; Phase 2 rounds and your own taps still go.

🪟 Windows · 🔑 Sign-ins · 📺 Live Mac mini · 📜 Mac log 30 days · 💬 Team talk

What: windows online/offline, each window's account, the live screen, every Mac log line for 30 days with search, and the running conversation between the Mac, the robots and the Claudes.

Fixing - the formats

FIX PACK

What: the one format every tool speaks. GAME: which game · FILE: the file · WHY: plain words + "PART: x" · TEST: how to see it · OLD: the exact lines now · NEW: the lines instead · END. Several OLD/NEW pairs allowed. Special kinds: STUDIO publish, NEW FILE (pieces/ mods/ JSON), COPY FROM a starter + CONFIG (a new game).

How: Workshop, Studio and Fix it write it for you; Paste a fix checks it; the window applies it exactly.

PART

What: every game is split into named parts (menus, track, car, garage, hud, sounds…). A job names ONE part in its PR title ("PART: car"); the robot fails a PR that touches another part. Fix one thing, break nothing else.

OWNER CHECK IN 30 SECONDS · ?test= links

What: every fix comes with one link that opens the game straight at the changed spot (apexf1.html?test=grid, ?test=rims…) so you judge it in 30 seconds, no menus.

mods/ · pieces/ · templates/ · looks/

What: mods/<game>.json = your Studio changes the game loads; pieces/ = Workshop scenes and tracks any game can load; templates/ = starter games; looks/<game>.md = the WHERE THINGS ARE map, KEEP/NEVER lists, references; looks/refs/ = the 5 reference pictures per game.

Robots (GitHub, no AI, always on)

Merge robot

What: merges every green PR by itself, merges main into a PR that fell behind, keeps both sides of notes files, writes missing CC-BY credits, never merges a draft or a .github change.

Game check · paperwork checks

What: on a PR: file guard (only the files the job may touch), PART GUARD (one part), LOOK GUARD (main vs PR pictures of menu/play per part - a changed part the title did not name = red), checklist lint, notes rules. Main gets the full play check; a merge that newly breaks a game is undone (auto-undo) with fair blame.

How to read it: ONE "🤖 Check status" comment on the PR: RUNNING / PASSED / FAILED + the Reason lines + evidence (error, 3 code lines, console, pictures).

Robot auditor · known faults · notes batch

What: auditor merges clean robot-file PRs (.github allow-list); known faults = robot-side measuring errors shown yellow (never a Muse's job) with an expiry; notes batch joins notes-only PRs hourly into one.

Model fetch + acceptance

What: a line in MODEL-REQUESTS.md (free Sketchfab link, real size in metres, no brand names) → the robot downloads, shrinks, measures (empty / stray piece / size / huge / tiny / blank pictures), rejects and re-asks by itself, takes 4 pictures; a nightly audit measures every model. Only a 3D model to pick ever reaches your phone.

Record 60 · play testers · branch sweeper

What: nightly one-minute recordings of every game with measured numbers; night play robots that mash, swipe and hold gas; a daily sweep of merged branches.

Phase 2 crews (the Muse windows)

Tester · Auditor · fixed pairs

What: Racer tester 8 / auditor 6, F1 7/5, Hockey 9/2, Track & Field 10/4, Baseball 3/1. A TESTER plays and measures and files ONE finding file per problem (how to see it, measured numbers, proof, STATUS: NEW) in one batch PR per round; an AUDITOR checks each NEW finding on main, fixes small ones itself (one part, one PR "FIX F-id (PART: x)"), marks 3D / engine / camera / physics / multi-part FOR-CLAUDE.

Rounds · T8-3 / A6-2 · ROUND DONE

What: the Mac sends each free window one round at a time (a checklist item or full play; an audit when its game has NEW findings). Round ids are T<window>-n / A<window>-n; a round is over when the window's chat says ROUND DONE.

FOR-CLAUDE · HELP-VP lines

What: a finding marked FOR-CLAUDE wakes a Claude through the mini to fix it (one PR each, before/after pictures). A window that is stuck writes ONE "HELP-VP: window N · what's wrong" line in jobs/HELP.md; a Claude answers "FIXED:" under it and the Mac types the answer back.

Owner's part

What: you play, send pictures + notes in a batch, tap thumbs, pick 3D models. Nothing else is supposed to reach you.

Words you will see

main · branch · PR · merge · green / red

main = the live code. A branch = a copy to work on. A PR (pull request) = "please put my branch into main". Merge = it went in. Green = the robot passed it; red = it failed, with the exact lines why.

UNIVERSAL.md · LESSONS.md · checklists/ · REALITY hook

UNIVERSAL.md = every lesson any window or Claude learned, read by all. LESSONS.md = the short live rules. checklists/<game>.md = real-sport measurements testers tick off. REALITY hook = numbers each game hands the robot (sizes, speed, ground contact) so it can measure instead of guess.

Ledger · proof · UNPROVEN

What: every Mac rule has a line that shows the time it last really fired. "UNPROVEN" = installed, never fired for real yet. Nobody may call a rule working before its line shows a time.

Away link · AWAY icon · PIN

What: the Mac mini opens a changing https link to its controller and posts it to a secret channel; your AWAY icon reads it and opens the real controller from anywhere. The PIN guards every page.

How do I…

…fix a colour, a size, a word?

Controller → 🔧 Fix it → the game → Broken → say it in your words → copy the message to ChatGPT (or Grok) → paste the answer → Check → Send. Or message the game's builder window directly with your words and a picture. Judge it with the ?test= link in the report.

…add a tree, a stand, a light?

Play the game with Studio ON → Place (drop it) or Scene (pick + move) or Lights → Save → Publish.

…change a track or add a circuit?

F1 / Racer with Studio ON → 🛣️ Track → drag points, move the finish line → Put it in the code → ▶ Run → Send. New circuit: "Save as a NEW circuit". Or Workshop → Track.

…roll a game back to yesterday?

Controller → 🕘 Versions → the game → ▶ Play that version to be sure → ↩️ Put this version back (two taps). Watch it on the PR page until merged.

…merge or send back a PR myself?

Controller → 🔀 Pull requests → the row → Merge it (green only) · Send back the red lines · Fix the conflict · Close it.

…make a problem a permanent check?

Studio → 🛡️ Rules → tap the thing → pick the rule → it must pass now → Send. From then on the robot fails any PR that breaks it.

…report a bug with proof?

On the Game Development page: ✏️ circle it, 🎥 record, 📤 send. Or Studio → 🐞 Log (errors with the line) and 👁️ Watch (the numbers) and say what you saw.

…make a new game?

Workshop → 🎮 New game → name, starter, track, scenery, car, colours, laps, rivals → Make it → Send. It shows under NEW GAMES by itself once merged.

…get a 3D model?

Message the game's builder: "add a line to MODEL-REQUESTS.md: <free Sketchfab link>, length N m, no brand names". The robot fetches, measures and shows you pictures to pick.

…see what is left to build?

Controller → 📋 Master list (live), filter Not done.

Engine core + game sheets built Nov 8

Fixed-step simulation, seeded random, recorded inputs → any run replays frame-exact on your phone and in the robot. Pause, step one frame, slow motion built in.

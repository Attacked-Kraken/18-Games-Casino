APEX SPORTS HUD KIT
===================
These are live on-screen displays for racing and sports games. There is no library and no build step.
  hud.js      <script src="hud.js"></script>
              var hud = ApexHUD.mount(document.body, {style:'neon', scale:1});
              hud.scoreboard({home:'RED', away:'BLU', homeScore:2, awayScore:1, clock:'04:12', period:'2ND'});
              hud.lapTimer({lap:2, laps:5, time:83.4, best:81.2});
              hud.positions([{name:'YOU',you:true},{name:'CPU 1'}]);
              hud.minimap({path:[[x,y],...], cars:[{x,y,you:true}]});
              hud.speedometer({value:142, max:240, digital:false}); hud.tachometer({rpm:9000, max:13000});
              hud.boost({value:0.6}); hud.countdown(3, onGo); hud.topbar({coins:1250, ...});
              hud.setStyle('cherry'); hud.show('minimap', false); hud.destroy();
              Call any widget again with new values every frame to update it.
  Styles: neon, cherry, lime, grape, steel
  png/        105 ready-made PNGs (5 styles x 21 pieces: scoreboard frames, blank boards,
              gauges, needles, timer and position panels, minimap frame, countdown 3/2/1/GO, and more)
Currency is shown as coins, never as real money.
Open preview.html for the Racing and Sports demos, with a style switcher and the countdown.
All content is original and generated by code. There are no brands, logos, real teams or recorded voices.

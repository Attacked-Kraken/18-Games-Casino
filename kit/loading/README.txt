APEX LOADING PAGES
==================
39 original, standalone, offline HTML loading screens for Apex Arcade games. Free to use in your paid apps.
Open index.html to preview them all (each runs in demo mode with fake progress).
pages.json lists each file with a one-line description. MUSE-GUIDE.txt explains how to customize them.

Styles: progress bar, striped bar, spinner, dots, progress ring, percent counter, race track, coin fill,
bouncing ball, neon sign, arcade marquee, tip carousel, run cycle, puzzle assemble, ocean wave, rocket launch,
pixel retro, minimal, glitch, card flip (picture cards), countdown, parallax scene, hourglass, orbit, heart fill,
battery charge, gem grow, typewriter, 3D cube, equalizer, snake dots, tower build, star collect, liquid flask,
pulse logo, road trip, bubble pop, day/night, rainbow arc.

API in every page: setProgress(0..1), setTip(text), done(). Set CONFIG.demo = false in the real game.

APEX TUTORIAL KIT
=================
Animated "how to play" hints for touch games. Add it with <script src="tutorial.js"></script>
  ApexTutorial.tap(el)  .doubleTap(el)  .hold(el,{ms})  .swipe(el,'left')  .drag(fromEl,toEl)
  .pinch(el)  .tilt(el)  .arrow(el,'down')  .ring(el)  .spotlight(el,{text})
  ApexTutorial.steps([{el:'#jump', gesture:'tap', text:'Tap to jump', waitFor:'click'}, ...],
                     {id:'intro', done:fn})   // a guided tour
  ApexTutorial.card({icon:'coin', title:'Collect coins', text:'...', id:'coins'})
  Show-once: ApexTutorial.once('intro')  returns true only the first time (saved in localStorage).
             .seen(id) .markSeen(id) .reset(id) .resetAll()
  .setStyle('grape')   .clear()   .iconSVG(name)   .handSVG()
  Styles: neon cherry lime grape steel
  png/  135 PNGs: hand pointer (normal, pressed, 3 frames), plus for each style: arrows, swipe arrows,
        tilt phones, rings, tap ripple and 12 card icons
Known limit: overlays are placed when shown. If the screen rotates or resizes, call the hint again.
Open preview.html and tap any demo.
All content is original and generated by code. There are no brands, logos, real teams or recorded voices.

APEX WEATHER + RACING FX
========================
This kit extends the existing Effects-Library engine. effects.js is that same engine, copied here,
and weather.js adds 28 new effects plus weather systems.
  <script src="effects.js"></script><script src="weather.js"></script>
  fx.weather('rain_storm', {intensity:1, wind:0.4, prewarm:true});   fx.stopWeather();
     kinds: rain_light rain rain_heavy rain_storm snow_light snow blizzard fog fog_heavy wind wind_leaves
  fx.setWind(-0.5)
  fx.play('sparks', x, y)  also: lightning lightning_flash tire_smoke tire_smoke_burst burnout
     skid_mark skid_drift dirt_spray gravel_spray mud_splash sparks_scrape puddle_splash water_spray
     rain_splashes dust_cloud
  fx.skidLine(x1,y1,x2,y2,width)  draws marks that stay on the track; fx.skidFade(), fx.skidClear()
  var e = fx.emitter('tire_smoke', () => [car.x, car.y]); ... e.stop();   follows a moving object
  ApexFX.weatherList(), ApexFX.sound(name) gives the matching sound file name
Sounds are in the separate Weather-Racing-FX-Sounds kit. Unzip both kits next to each other and
turn on Sound in preview.html.
Open preview.html for a top-down track with a drifting car, and tap any effect button.
All content is original and generated by code. There are no brands, logos, real teams or recorded voices.

# LIBRARY - one page per game (owner Nov 3 2026, LOCKED)

- `library/open/<game>.md` = a game still being worked on. Its AUDITOR keeps the page current after every audit round:
  "What's left" (open findings, BLOCKERs first), "Fixed this week", "Waiting on the owner", checklist progress.
  Anyone (Claude, a window, the owner) can read one page and know where that game stands.
- `library/closed/<game>.md` = a game that is FINISHED and already went to the Apex Arcade. Only the owner says when a
  game closes; Claude moves the page (the open page is deleted, the closed page says the date, the Arcade name and where
  its files went). A closed game gets no tester rounds, no auditor rounds and no findings - anything new about it is
  Apex Arcade work.
- Games with no crew (resting) still have an open page so nothing about them is lost.

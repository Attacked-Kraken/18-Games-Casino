# Look boards

One file per game: what the owner wants it to look like (MUST), what he never wants again (NEVER), and which lighting
preset it uses. **Every look board sits on top of `STUDIO-STANDARD.md`** (people, gear, phone budget, hard NOs). Every job from the owner's job board points the Muse here. 👎 lines from the owner's phone get added
by the Muse that received them — never removed.
